## Processing notes

- Static images were organized into categories.
- Existing `.webp` files were kept as `.webp`.
- JPEG/JPG inputs were converted to high-quality WebP.
- PNG inputs were converted to lossless WebP with alpha preservation where applicable.
- Animated/video files are not included in this repository.
- File names preserve source identifiers where available to make provenance easier to inspect.

## Removal requests

If you own rights to an image and want it removed, open an issue or contact the repository owner with the file path and proof of ownership.
